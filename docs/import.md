# GenBank and GFF3 import

```bash
cellgen convert assembly.gbk
cellgen convert annotation.gff3
```

The browser accepts `.gb`, `.gbk`, `.genbank`, `.gff` and `.gff3`. Python uses `from_genbank_file` and `from_gff_file` from `cellgen.genbank`; GenBank requires BioPython. EMBL is not implemented or tested. A file is one cell containing all its sequence records. The importers do not infer that two files describe the same cell, or infer multiple cells within a file. For multiple cells, import separately and join validated CellGen records with `;`.

GenBank requires at least one `LOCUS` record and parsable features. GFF3 requires a nine-column feature row, `##sequence-region`, or embedded FASTA sequence header. A GFF3 `##FASTA` block is optional: coordinates alone suffice for a structural record. Sequence length comes from a `##sequence-region` beginning at 1 or from embedded FASTA. If a region starts elsewhere, `region_start` and `region_end` are retained without claiming full sequence length. Malformed GFF3 rows and invalid coordinates produce line-numbered errors. GenBank source sequence and GFF3 FASTA are not used to discover features.

An explicit GenBank definition or source `/plasmid` qualifier makes a plasmid; an explicit chromosome definition or source `/chromosome` qualifier makes a chromosome. GFF3 chromosome/plasmid feature types have the same effect. As a fallback only, a record ID containing the literal word `plasmid` or `chromosome` (case-insensitive) classifies that record; this is a name inference, not verified biology. Otherwise it remains a curly-brace entity with `type="unknown"`; a short or fragmented contig is not silently made a chromosome or plasmid. A single GenBank record whose full span is annotated as a mobile element becomes a standalone entity. An empty chromosome such as `()chr` is valid when its record is classified as a chromosome and contains no retained features.

GenBank importer feature types include `mobile_element`, `transposon`, `insertion_sequence`, `integron`, `gene`, `CDS`, and an `integron` described in a `misc_feature` note. GFF3 includes `mobile_genetic_element`, `transposable_element`, `transposon`, `insertion_sequence`, `integron`, `repeat_region`, `gene`, and `CDS`. Other annotations are omitted. A mobile element feature never classifies the entire GFF3 sequence as a plasmid. Feature coordinates are one-based inclusive within their source accession; strand, type, start and end are retained. Distinct same-name features at distinct positions stay distinct. Gene/CDS pairs with the same span and an explicit GFF3 `Parent` link are represented once.

Features are attached to the smallest **strictly enclosing** non-gene feature on the same source record. Equal boundaries are siblings; partial overlaps are siblings, and ties among equal-sized enclosing parents use input order. This coordinate rule does not establish biological parentage by itself; inspect unusual overlaps. An annotated chromosomal AMR gene outside a mobile element stays on the chromosome only when the user selects it. Import never invents an MGE parent.

By default, uncontained genes and CDS are omitted to avoid rendering every chromosomal gene; genes inside retained structural features stay. In Python, `retain_uncontained_genes=True` retains all, while `selected_feature_ids={"blaKPC-2"}` retains only matching uncontained genes. The browser offers the same two choices before the Import button. Match the exact GenBank `/gene`, `/locus_tag` or `/label`, or GFF3 `ID`, `Name`, `gene` or `locus_tag`; several identifiers can be comma-separated in the browser. The browser reports retained feature and omitted uncontained gene counts and lists unmatched selected IDs. Python silently ignores unmatched identifiers, so inspect the result when using that API. No gene-name pattern is treated as proof of AMR: if the annotation lacks these fields, a user must supply a better annotation or edit the CellGen record. A matching label alone says what was annotated, not that resistance was confirmed.

Imported `accession`, sequence length when known, topology when supplied, coordinates and strand record provenance. GFF3 `Name`/`ID` and GenBank qualifiers become labels. The file path and detector/database versions are **not** embedded automatically; record those separately when reporting an analysis. Import is an interpretation of existing annotations, not sequence-based MGE detection or plasmid typing.
